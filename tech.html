NO. 03 — 之四

Tech

每个系统的脾气，都得亲手折腾过才知道。

iPhone 只在没有实际使用时具有强吸引力，一旦上手就会被它的各种限制膈应。下面是这些年换过、修过、root 过的一堆设备留下的使用笔记——问题清单式，脾气秉格式。

01

各家的脾气

DEVICE NOTES

iPhone

iOS 封闭性样本
  • 每七天需要刷新一次测载软件
  • 浏览器均为 WebKit，没有真正的 Tor 浏览器。Onion Browser 有 WebRTC 泄漏真实 IP 的问题
  • 获取应用不自由，只能在 App Store 里找
  • 苹果硬件每代独占新功能，计划报废旧设备
  • 部分基础设施应用需付费购买或订阅
  • IM 聊天软件的内容形态受限（Telegram 可以在网页端解除限制，Discord 的客户端锁死不允许看 NSFW 群组）
  • USB 共享网络需要目标电脑安装 iTunes
  • 最右边有一个无法关闭的应用程式一览
  • 隐藏应用不彻底，在部分记录（电池使用）中仍然可以看到被隐藏的应用的名字
  • 被隐藏的应用退出就不会保留后台，每次进入应用都需要进行一次人脸识别
  • iCloud 默认开启，下载支持 iCloud 存储的应用后会默认开启 iCloud 存储
  • 内购只能用商店所属地银行卡付款
  • 礼品卡余额可能要求先绑定银行卡
  • Apple 账号如果开了 Find My 然后又被封号的话，会导致设备被锁定无法退出
  • 充值只能买礼品卡
  • Apple 账号的跨区使用严格来讲是违反使用协议的
  • 无法根据应用程序分流，不能一边听 YouTube Music 一边看知乎
  • 无法和电脑版 Firefox 同步书签
  • Reddit 现在强制要求手机浏览器不得观看 NSFW 内容，必须下载客户端，但 Android 的 Firefox 有插件可以绕过这个限制
  • 没有 Muzei 和 Pixiv for Muzei3 可以自动更换并下载壁纸
  • 通过微软照片导入的照片会导致原图片和叠加层分离，比如一张 HEIC 后面跟一个同名的 AAE

Pixel

Android 原生 理想主义者
  • 状态栏图标需要应用特别适配，没适配就是一个圆形，很难看（AOSP 系列通病）
  • 芯片性能严重落后骁龙
  • 游戏中心只有屏幕截图快捷方式、屏幕录制快捷方式、FPS 计数器、免打扰快捷方式，以及一直「不适用此游戏」的优化模式、成就——排行榜以及 YouTube 直播，没了，费拉了一点
  • 所有 AOSP 类系统的滚动截图都需要应用特别适配，不像三星、一加系统自带的长截图一样直接暴力截图
  • VoLTE / VoWiFi / 5G 等通讯功能受谷歌运营商白名单的影响，在不受支持的国家不可用
  • 主用户和多用户安装同一个应用，该应用可能会在其中一个用户中无法正常工作——Chrome、Muzei、Syncthing Fork、v2rayNG 都中过招（这是所有 Android 的通病）
  • 多用户会降低整体性能
  • 谷歌在限制 hook 行为：audio policy 变成 AIDL 接口、Iconify……
  • Android 过去用 XML 构建 UI，Android 15 起过渡到 Jetpack Compose，16（QPR）开始 UI 完全由 Compose 构建。与 XML 不同，Compose 更难修改或挂载——代码在构建时内联并大量优化，难以追踪或更改；加上 Compose 不断重绘 UI，可靠挂载非常困难。因此我们无限期归档此项目，直到找到更好的方案——某 hook 项目作者的停更声明， Pixels 生态的缩影
  • 难以绕过的 Strong Play Integrity

索尼 Xperia

Sony 颜值欠费
  • Xperia 全系列的 SD 卡读写速度上限是 50MB/s
  • 没有系统自带的双击唤醒和双击睡眠
  • 没有彩色通知图标（AOSP 通病）
  • 没有自带的滚动截图（AOSP 通病）
  • 系统不如三星或一加手机美观，天差地别——光靠 root 后可用的社区美化模块根本救不回来
  • 控制中心下拉后固定是不可更改的一片纯黑色
  • 时钟样式只有两种，而且都不美观
  • 状态栏图标遵循了 Android 传统，不如 Pixel 那种美化过的好看
  • 主屏幕-系统颜色-其他颜色中的可用色只有固定的两个，Pixel 有十个出头
  • 设置页面的图标不像 Pixel 一样受 Material You 控制（变色、功能性图标外围绕一圈圆再上色），永远是单色——LineageOS 家族那种单调的系统也是这样
  • fastboot 找驱动麻烦（newflasher 会提供）
  • Xperia Companion 找驱动也很麻烦（在安装文件内藏着）

三星

One UI 区域限定狂魔
  • 多语言支持不够：Good Lock 和 Good Guardians 没有繁体中文，Bixby 也没有
  • 相机拍出来不够自然，看起来像是被刻意美化过
  • 三星账户强制绑定手机号码
  • 不论哪个国家的固件都自带一个杀毒软件，比如 McAfee
  • 部分第一方软件有区域限制（三星商店靠 SIM 卡的国别码识别），想换区必须拔卡
  • 陆港台版本的三星键盘简体中文强制自带搜狗词库，且无法更改为其他版本硬件上的三星键盘（美版硬件的三星键盘没有这个问题）
  • 三星钱包根据固件和 CSC 严格限制区域，无法通用
  • 非国行系统的三星健康使用谷歌地图
  • 某些功能特定于固件：Blockchain 仅在 N 和 B 后缀的三星手机中提供
  • 检测到中国 SIM 卡会问你是否使用本地电池策略；插中国 SIM 卡无法注册其他国家的三星账号、无法使用视频通话流转
  • 增强的数据保护（三星云 E2EE）国行没有，港台有；Samsung Pass 国行也没有
  • 反取证工具因三星手机没有多用户导致 profile deletion 不生效（Shizuku+Dhizuku+无障碍权限没有能力删除安全文件夹）
  • Amarok 的拨号盘呼起不生效，索尼手机生效
  • Shizuku 后台运行时间长了会被杀后台
  • 屏幕壁纸不会随着页面滚动（索尼、Pixel 可以）
  • 各固件版本与 CSC 的差别实在太大，不通用
▍换机观察 · 从旧三星换到 S23 的有感区别

国区 Bixby 锁区了：以前非国行系统也可以用中国 Bixby，现在港版系统 Bixby 地区选不了中国，中文 Bixby 基本废了。Google 方面，国行会切断 Google 套件和服务器的后台同步，安卓消息推送基本收不到；也无法语音唤醒 Google 助理、无法将 Google 设为默认助理，意味着用不了 Google Lens 做当前界面识别。国行的系统安全插件由腾讯手机管家提供，且有定制的 APK 安装器——你安装的 APK 信息和 App 列表都会传给腾讯，这就看你介不介意了。AI 的差异：国行识屏 AI 是百度和京东，图片 AI 是美图秀秀，文字生成 AI 是 WPS。国行刷港版系统和直接买港版基本没有差别，唯一差异是系统信息里的设备硬件编码是国行硬件 CHC。

系统功能方面
  • 国际版预装 App 多：完整的 Google 全家桶、微软全家桶以及 FB，基本都无法卸载。据报道国际版 S23U 系统占用达到 60G，大部分为内置 App；国行非必要的 App 都可以卸载
  • 负一屏国行和其他国产手机差不多；海外系统为 Samsung Free 或 Google 探索，可自行设置
  • 国行安装 App 有专供安装器（带推荐应用推广和应用黑名单）；国际版装 APK 会过 Play 商店验证，速度没有国行快
  • 国行过度动画日常掉帧；国行浏览器为三星浏览器且主页带资讯页，港版为 Chrome
  • 国际版应用商店会根据 SIM 卡属地切换地区，国行锁国区商店；国行通话界面有黄页，国际版没有
  • 国际版文件 App 可以连接 OneDrive 和 Google Drive；国行有红包助手（红包提醒）
三星服务方面
  • 国内版账号和国际版不互通：用非国区 ID 的话，健康数据、云储存都无法同步
  • Samsung Pay 地区跟随系统版本，非国行系统无法绑定银联卡、公交卡及其他 NFC 凭证
  • 国行有专用 App：生活助手（优惠券、动车票行程提醒）、智能管理器（清理储存、应用锁、自启控制）
  • 国际版三星音乐由 Spotify 提供；Bixby 基本互通，但海外版无法用 Bixby 控制微信（国行可以）
  • 识屏服务国行主要是百度，国际版识图是 Pinterest、翻译是谷歌翻译
安卓原生功能 / 消息推送 / 协同
  • 国际版除 Bixby 外还有谷歌助理；国行可以自行安装谷歌助理但无法用 Hey Google 唤醒，也无法后台同步 Google 账号数据（Google 相册只能打开 App 同步）
  • 国际版文件分享用安卓分享，国行用互传联盟；投屏国际版是 Chromecast 协议，在 Google TV/Nest hub 上播放会自动弹出媒体控制器，国行不会
  • 国行喜欢杀后台，很多非国内 App 打开时才收到消息；国际版插国内卡开启本地服务后同样杀后台——又没有国行推送服务，结果国内外 App 都收不到消息，达成「与世隔绝」成就
  • 微信在两个版本里都是保活的
  • 国际版可与微软账号协同：笔记同步 OneNote、相册同步 OneDrive、提醒同步微软 ToDo、剪切板与 Windows 同步、系统内置微软手机助手

一加 / OPPO

OxygenOS · ColorOS 刷机困难户
  • 电话卡区域锁定：中国版手机带到国外用会被禁止通讯功能
  • ColorOS 两大问题：自带的浏览器无法通过 adb 权限或设备所有者权限删除；修改设备名称必须联网校验、无法绕过
  • 中国版固件刷外国版固件会损失一些功能，不过一般 root 可解决——比如一加 13 的信号、一加平板 2 Pro 的手写笔（系统白名单）
  • OxygenOS 也包含了很多 ColorOS 的组件；OPPO 和 OnePlus 的代码库已经统一
  • OxygenOS 无法为 Firefox 使用硬件视频解码
  • 刷氧 OS 回锁会无法 OTA，一旦 OTA 就不开机——一加 13 在 dtbo 上做了手脚，干扰国行刷氧 OS
  • 9008 锁定，只有 OPPO 售后有权限操作 9008
  • OxygenOS 中台湾不叫台湾，而是叫台北
  • 开发者选项里有个「禁止权限监控」按钮，不开启会阻止 Shizuku 正常工作
  • 有 OTG 连接选项：不开则外置 USB 存储设备无法使用；不能常开，10 分钟无设备自动关闭
  • OxygenOS 手机版有手机管家；平板的工作列固定有设置软件，不可更改位置或移除
  • 13 英寸平板不适合玩游戏，划视角操作受限；横版和竖版会影响桌面壁纸的可见度（比例会变）
  • 阅读 PDF 电子书始终是一项艰难的工作，不管用平板、电脑还是手机
  • 一加 Pad 2 Pro 的原厂音频解析度还可以，但分离度不行，声音混在一起；默认音频质量不好，需要模块补救
  • OxygenOS 无法使用 duress、无法正常工作；也无法使用 NFC Card Emulator Pro
  • 多用户没有「VPN 始终开启」和「封锁非 VPN 流量」的功能
  • 相册的编辑功能会将图片送给深圳万普拉斯处理；如果删除谷歌相册，一加相册会一直提醒你谷歌相册已被删除、备份不可用
  • Android 系统会持久通知 VPN 已开启；v2rayNG 如果在开启后立刻被划掉后台，就会自己关闭
  • 有锁屏密码的情况下禁用应用需要输入锁屏密码；后台锁定最大只允许五个
  • 反复更新以及 COS 和 OOS 之间日益扩大的差异，最终导致需要禁用 vbmeta 才能启动；分析 odm.img 时还注意到音频、充电、摄像头、显示、蓝牙和 Wi-Fi 配置的细微差异——好在实际使用未造成显著问题——来源：XDA Forums · Magisk Module「Stylus Fix for OnePlus on Different Regional ROM」
02

机械硬盘守护手册

HDD SURVIVAL GUIDE

机械硬盘本质上是一台超高精度的物理微型机械——全速运转时盘片转速相当于直升机螺旋桨的十几倍，磁头与盘片的距离只有几纳米（人类头发丝的万分之一）。以下规范用于保护素材、工程文件和核心数据。

🛠️一 · 日常摆放与运行禁区

核心禁区：通电读写（传文件、渲染导片、读游戏）时，绝对不能移动、翻转、磕碰或摇晃硬盘盒/机箱——任何轻微位移都会让磁头直接「坠机」划伤高速盘片，造成永久性物理坏道和数据全灭。键盘大力敲、桌子不稳、宠物跳上桌都是隐患。
远离大功率 HIFI 音箱：严禁贴着音箱摆放或放在两台大功率音箱正中间。低音共振会导致磁头寻道错误、速度暴降甚至划盘；强力磁钢会逐渐磁化盘片，发生「文件无故损坏、CRC 校验错误」的内伤。
安全动作：放在稳固平整的水平面；硬盘距离音箱 50 厘米以上，受限时音箱下垫避震海绵，硬盘与音箱之间用铁/钢制结构件做物理磁屏蔽。

🔌二 · 供电与接口安全

先安全弹出再断电：严禁在硬盘正在读写、或刚传完还没等几秒时直接拔 USB 线/关电源。突然断电会让磁头来不及复位，直接「拍」在盘片上；还极易破坏文件系统路由表（MFT），整块盘变 RAW。
拒绝供电不足的接口：3.5 寸大机械必须用带独立 12V 外接供电的硬盘盒，严禁劣质无牌供电线；2.5 寸移动硬盘严禁插机箱前置 USB 或无独立供电的廉价 Hub——电压瞬间下掉会导致频繁磁头复位、中途掉盘，烧电路板或出坏道。
安全动作：关机前在任务栏点「安全删除硬件并弹出媒体」，看到提示再断电；移动硬盘插主机背面主板原生的 USB 3.0/3.1（蓝色、红色或 Type-C）接口，确保 5V 供电足额。

🌡️三 · 环境与维护管理

警惕 50°C 以上持续高温：严禁放在密闭「闷罐」外壳内或机箱出风口附近。长期 50–60°C 会让主轴轴承润滑油脂加速挥发干涸——机械磨损加剧、噪音变大、寿命折半。
防静电与科学冷备份：裸盘手拿时严禁触摸背面绿色电路板（PCB）和金手指，人体静电可能瞬间击穿主控芯片。
安全动作：用 CrystalDiskInfo 观察温度，控制在 45°C 以下；批量倒大文件时卸掉闷罐盖子「物理开颅」散热，或用小风扇对准吹。拿裸盘握两侧金属边缘。推荐「用完即关/拔」的冷备份——只要不通电，硬盘对震动、高温甚至磁场的耐受度提升几十倍，磁头零磨损，寿命无限延长。

📊 四 · 健康自我体检（每 2–3 个月一次）

关键 IDS.M.A.R.T. 属性正常状态异常危险信号
05 重新分配扇区数
Reallocated Sectors Count		 000000000000 只要不为 0：说明有物理坏道已被屏蔽，盘片开始损坏。
C5 有待处理扇区数
Current Pending Sector Count		 000000000000 只要不为 0：说明有疑似坏道正在等系统校验，极易卡顿、死机。
C6 不可校正的扇区数
Uncorrectable Sector Count		 000000000000 只要不为 0：严重的物理坏道，数据已经开始丢失，磁头寿命将尽。
🚨 终极警告：任何机械硬盘都存在突然暴毙的概率。05、C5、C6 一旦亮黄色警告，请立刻停止写入任何新数据，并全速将内部核心数据备份到 SSD 或其他安全介质中。数据无价，谨慎操作！

折腾实验室

TINKER LAB

绕过三星健康监测的地区限制（Shizuku + JumpReplay）

三星健康的部分监测功能有地区限制。在 JumpReplay 的意图拦截器（Shizuku + 系统助手）中输入以下命令，直接拉起三星健康主界面：

intent:#Intent;launchFlags=0x10400000;component=com.samsung.android.shealthmonitor/com.samsung.android.shealthmonitor.home.ui.activity.SHealthMonitorMainActivity;end

手表启动 Shizuku v13.7.0 · 三步定位法

在手表这类特殊设备上启动 Shizuku 时，先用 adb 摸清它的底细，把输出发给 AI 让 AI 拼命令：

# ① 调查包名 adb shell pm list packages | findstr /i "shizuku" # ② 调查安装路径 adb shell pm path moe.shizuku.privileged.api # ③ 调查原生库目录 adb shell dumpsys package moe.shizuku.privileged.api | findstr /i "nativeLibraryDir"

永久 root 既要对抗谷歌三绿，又要隐藏 root 对抗各路应用的检测，强依赖于社区各组件的更新。而通常检测方案来得比社区隐藏方案快，很尴尬。
